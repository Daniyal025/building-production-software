# Grader prompt (used for every scenario)

> You are a strict, impartial principal engineer grading answers. Read ONLY: (1) the "## S<n>" section of the rubric and (2) the ten answers R01.md … R10.md in the blinded folder. Do not read any other file or folder.
>
> The answers come from different, anonymous sources. Score every answer against each of the 12 rubric items: 1 = clearly and correctly present, 0.5 = partly present or only implied, 0 = absent or wrong. Judge substance, not wording; do not reward length, extra scope or confident tone; penalise incorrect advice under the relevant item. Grade each answer independently.
>
> Write a JSON file `S<n>-scores.json` of the form `{"R01": {"scores": [12 numbers], "note": "one sentence"}, ...}` for all ten answers.
